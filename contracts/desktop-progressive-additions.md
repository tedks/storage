# Contract for late directory additions in Nautilus

This first slice specializes the [desktop listing changes contract](desktop-listing-changes.md) for a native `file://` directory on an explicitly selected Storage mount. Its inputs are committed discoveries from a progressive enumeration. A desktop poll or subscription must never start a remote listing, fetch file contents, mutate a file, or hold a FUSE callback waiting for a client.

**Producer.** Publish a child only after the merged listing is visible to a subsequent lookup. An empty or failed member contributes no additions. An obsolete enumeration cannot publish into a newer one. Duplicate discoveries of a child already present in the union do not represent another addition. If freshness cannot be established, signal that reconciliation is required.

**Delivery.** Bind each subscription or cursor to the mount instance and exact relative directory. Authorize local peers using the mount owner's private endpoint. Limit retained events, bytes, request sizes, active resources and polling work. A basename must represent one native path component including support for valid non-UTF-8 bytes or explicit degraded handling. Validate it before constructing a child location. Filenames are necessary in the scoped data channel and must stay out of status, metrics and logs. A client that misses retained history must detect the gap. A mount generation change invalidates old work even when the mount path is reused.

**Client.** Scope registration to a monitor whose local path lies within the selected mount. Deliver each addition on that monitor's owning main context. Never target a window by focus or active tab. Cancellation, navigation and destruction end interest in that monitor. Hold no dangling references during queued delivery. Cover publication racing initial attachment through retained history or a bounded reconciliation. Never mark a missed interval as delivered. Unrecoverable gaps leave the adapter visibly degraded until a fresh baseline. A full refresh is safe only when it targets the exact interested directory.

**Acceptance.** One synthetic member answers, the window renders its row, a held sibling contributes another child, and the same window renders both with no manual action. The disabled-adapter control keeps the first row only until refresh. Another monitor stays quiet. Exercise duplicate contributions, stale revisions, disconnect, gap, unusual basenames, monitor teardown and remount. The tracer can demonstrate individual boundaries before all release cases pass. Confirm the complete chain against the target Nautilus/GIO pair before recommending installation.
