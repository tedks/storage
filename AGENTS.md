# Agent Guidelines

## Before committing
- Use the provided virtual environment setup (for example, run `setup-venv.sh`), activate it, and run tests from that environment.
- Run the test suite before committing to catch regressions early; if you cannot run tests, note that explicitly.

## Git workflow
- Make commits small and granular so each change is easy to review and revert.
- Commit frequently to keep history focused and incremental.
- Write detailed commit messages that describe what changed and why.
- Do not use emojis in commit messages or documentation.
